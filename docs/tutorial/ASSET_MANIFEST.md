## Excluded material

- Full-screen raw captures were used only to calibrate crop coordinates and
  were not added to the repository.
- The full Zotero diagnostics dialog was excluded because it displays a local
  Server ID.
- The complete Project Manager list was excluded because it contains unrelated
  project names and local workspace paths.
- Private notes, the full Vault file tree, API keys, library IDs, and account
  information are not present in the retained tutorial set.
